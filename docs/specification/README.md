# ANA v0.1 Core Specification

The documents below are the normative source for the `ana-core-chain` v0.1
minimal profile. The release is Draft / Experimental; “normative” means these
documents control the repository's conformance suite, not that ANA is a
finalized external standard.

| RFC | Language entry points | Scope |
| --- | --- | --- |
| RFC-0001 | [English](../RFC-0001-Architecture.md) \| [简体中文](../RFC-0001-Architecture.zh-CN.md) | Local-first architecture and layered protocol model |
| RFC-0002 | [English](../RFC-0002-ANA-Chain.md) \| [简体中文](../RFC-0002-ANA-Chain.zh-CN.md) | Canonical framing, State Delta, versioning, and minimal Chain fallback |
| RFC-0003 | [English](../RFC-0003-Envelope.md) \| [简体中文](../RFC-0003-Envelope.zh-CN.md) | Provider-neutral task Envelope |
| RFC-0004 | [English](../RFC-0004-Memory-System.md) \| [简体中文](../RFC-0004-Memory-System.zh-CN.md) | Memory ownership, portability, disclosure boundary, and current limits |
| RFC-0005 | [English](../RFC-0005-Agent-Runtime.md) \| [简体中文](../RFC-0005-Agent-Runtime.zh-CN.md) | Local Runtime roles, Provider boundary, Executor, and Safety Policy |

The fixed requirements that are executable today are summarized in
[conformance](../conformance.md) and represented by the
[test vectors](../test-vectors/README.md).
