# ANA v0.1 Core Specification

The documents below are the normative source for the `ana-core-chain` v0.1
minimal profile. The release is Draft / Experimental; “normative” means these
documents control the repository's conformance suite, not that ANA is a
finalized external standard.

| RFC | Scope |
| --- | --- |
| [RFC-0001](../RFC-0001-Architecture.md) | Local-first architecture and layered protocol model |
| [RFC-0002](../RFC-0002-ANA-Chain.md) | Canonical framing, State Delta, versioning, and minimal Chain fallback |
| [RFC-0003](../RFC-0003-Envelope.md) | Provider-neutral task Envelope |
| [RFC-0004](../RFC-0004-Memory-System.md) | Memory ownership, portability, disclosure boundary, and current limits |
| [RFC-0005](../RFC-0005-Agent-Runtime.md) | Local Runtime roles, Provider boundary, Executor, and Safety Policy |

The fixed requirements that are executable today are summarized in
[conformance](../conformance.md) and represented by the
[test vectors](../test-vectors/README.md).
